# `phone/` — the standalone phone app

A small static web app that gives the user a NihilPointZero **home-screen app**
that works on mobile data with the PC switched off.

It exists because the studio is a Windows Electron app: an `.exe` cannot be
installed on a phone, and Electron cannot produce an Android build. A web app the
phone can install is the only real way to put NihilPointZero on a handset.

## What it does and deliberately does not do

| Does | Does not |
|---|---|
| Ideas, script writer, thumbnail briefs, advisor | Video rendering, voice-over, subtitles, charts |
| Saves its own output on the phone | Reach the PC's `nihilpointzero-data` in any way |
| Works with no key at all (free Pollinations) | Feature-length 90/180-minute scripts |

The limits are shown to the user inside the app rather than being quietly
missing, because pretending would waste their time.

## Why it imports from `src/`

`phone/src/ai.ts` imports `src/main/prompts.ts` and `src/main/llm/parse.ts`
**directly** instead of copying them. Those modules only import types, so they
bundle into a browser cleanly, and the phone can never drift away from the
desktop's writing style. `phone/src/phone.test.ts` asserts that parity.

## Layout

```
phone/
  src/      app.ts (UI) · ai.ts (providers) · store.ts (phone storage) · phone.test.ts
  public/   index.html · manifest.webmanifest · sw.js · icons   (copied verbatim)
  dist/     build output — gitignored, regenerated by the build
```

## Commands

```
npm run typecheck:phone   # tsc against tsconfig.phone.json (DOM libs, no node types)
npm run build:phone       # esbuild -> phone/dist
node scripts/phone-smoke.mjs   # click-through test in a real mobile-sized browser
npm run publish:phone     # build, then push phone/dist to the public Pages repo
node scripts/make-phone-icons.mjs   # only when the icon mark changes
```

## Hosting

The studio repo is private and GitHub Pages needs a paid plan for private repos,
so the built site is pushed to a separate **public** repo that contains only the
build output — no source, no keys, no user data:

<https://dskjazz.github.io/nihilpointzero-phone/>

## This does not touch the desktop build

Nothing here is referenced by `electron.vite.config.ts`, `electron-builder.yml`,
`tsconfig.node.json` or `scripts/ship.ps1`. `npm run dist:win` and `npm run ship`
behave exactly as they did before this folder existed.
