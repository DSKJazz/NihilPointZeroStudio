AM I CURRENT? ..... Settings -> Version box at the top. Says up to date / newer available /
                    could not check, and shows both version stamps. "Check now" re-checks.
UPDATES ........... nothing to do. The studio opens when Windows starts and installs
                    anything new right then, before you sit down. Never during a render,
                    and never when YOU opened the app yourself. Off switch: Settings ->
                    "Open the studio when Windows starts".
UPDATE BY HAND .... open the app. If a blue "A newer version exists" notice appears at the
                    bottom, press "Get the update". Done - the app downloads it, starts it
                    and reopens updated. Say yes to Windows once. No web page, no Downloads
                    folder, no File Explorer.
                    WHOLE WORKSHOP TOO? double-click UPDATE-MY-STUDIO.cmd in the code folder
                    - that also refreshes the code folder, your Desktop folder and GitHub.
                    5-10 min, walk away.
RUN IT ............ EITHER double-click NIHILPOINTZERO-OS-portable.exe (portable; unpacks ~40-60s)
                    OR run NIHILPOINTZERO-OS-setup.exe ONCE to install -> opens in ~2s from then on,
                    taskbar pins are SAFE, and it uses the SAME data folder (same videos/settings).
MOVE IT ........... copy the WHOLE "NihilPointZeroStudio" folder -> paste on any PC -> run the portable exe
GOLDEN RULE ....... keep the .exe and "nihilpointzero-data" folder together, always
BUILD BADGE ....... the sidebar (under "OS") shows e.g. "v0.1.1 · 2026-07-19 15:59 · 4e5e704"
                    (version · exact build date+time · code id). Written AUTOMATICALLY at build time —
                    THAT is proof of which build is running. Don't see the expected badge? See below.
DON'T PIN THE RUNNING PORTABLE EXE ... a taskbar/Start pin made while the PORTABLE app is open freezes
                    to a temporary copy and keeps launching OLD code forever. (The INSTALLED version
                    has no such trap — pin it freely.) This was the #1 cause of "my updates didn't show".
MAKE SHORTS ....... Video Studio -> any video -> "📱 Cut into vertical shorts" -> it finds the best
                    moments itself and makes 9:16 captioned clips for Shorts/TikTok (free, offline)
STUCK? ASK IT .... click 🎬 Producer (bottom-right of EVERY tab) and ask "how do I ...?" — it knows every
                    tab and button of this studio and gives you the exact steps. 📖 Detailed / ⚡ Brief
                    buttons set how long the answer is.
JUMP ANYWHERE ..... press Ctrl-K, type a tab (e.g. "scene"), Enter
AUTOSAVE .......... work saves itself ("Saved ✓" near the title) and survives restart
WHERE'S MY WORK ... the folder is PINNED (decided once, written down) so the app can never
                    quietly move house. Settings -> "Where your work is kept" names it. If finished
                    videos are ever found in a folder the app isn't using, it says so there and
                    offers "Bring them into the app" (copies them in; deletes nothing).
BACKUPS ........... automatic weekly copy to C:\Users\<you>\NihilPointZero-Backups. Lost something?
                    Settings -> Backups -> "Restore missing files" (never overwrites current work).
                    Optional second home (USB) + delete-sync (delete in app = gone from backup too).
ONLY YOU DELETE ... every delete asks you to confirm; the AI can create/edit but NEVER deletes.
                    Deleting a video also removes its backup copy (delete-sync, off-switch in Settings).
RED DOT on Settings = the weekly self-check found a real problem -> open Settings -> Run full check
IF A CHANGE DOESN'T SHOW ... check the BUILD BADGE. If it's old: you launched a stale taskbar/Start
                    pin — use the Desktop shortcut or the .exe directly, then fully close + reopen.

------------------------------  NEW (2026-08-01)  ------------------------------------------------
WHAT CHANGED ...... Settings -> "What changed" lists what is new in the build you are RUNNING.
                    Only things really in it — nothing is advertised before the code ships.
YOUR CHANNEL ...... a new tab. Reads YOUR OWN videos and tells you which title shapes actually
                    worked here, which day and hour your audience shows up, and which of your
                    videos form a series (with the description/pinned-comment/end-screen links
                    written for you). Also reads your COMMENTS and ranks the questions people
                    keep asking, quoted word for word. Needs the YouTube key + channel ID in
                    Settings; costs about 4 of the 10,000 free daily requests.
CARETAKER ......... Settings -> the studio checks itself: health, dead AI rescue, lost videos.
                    Recommended every 6h + at app start (the why is on the card). You set the
                    schedule, pause it, run it now, delete its record. Never runs during a render.
AI SWITCHBOARD .... Settings -> every AI brain with a plain ON/OFF switch + "Use this one".
                    OFF means never contacted, not even as a backup. The old free online AI
                    (went paid) is OFF; your local brain stays ON; paid ones stay asleep.
CONNECT GEMINI .... Settings -> "Connect Gemini" -> "Show me how". Google gives the key away
                    FREE (no card): 2 minutes, buttons for each step, tested for real before
                    saving. ChatGPT/Grok have no free machinery, so they get open-in-browser
                    buttons — the studio never stores your passwords.
CONNECT YOUTUBE ... Settings -> "Connect YouTube" -> "Show me how". Free, ~3 min, no card. Five
                    steps, each with a button that opens the exact page. Paste the key, press
                    Check: the app really tries it and says in plain English what is wrong and
                    which step fixes it. Then type your @name and it finds your channel ID for
                    you (YouTube hides it three menus deep) and shows the channel name back so
                    you can see it got the right one. Empty result? It now says WHICH of the
                    seven reasons — including "could not reach YouTube", which is not the same
                    as "you have no videos". RED = wrong, here is the fix. AMBER = could not
                    tell, nothing for you to do.
READ IT TO ME ..... Script Writer -> hear your script spoken at 2x, with a list of what to listen
                    for: sentences too long for one breath, a word said twice, a number you cannot
                    read aloud, a line that switches language. A 12-min script proofs in 6 min.
5 OPENINGS ........ Script Writer -> "Show 5 openings" -> five different first-15-seconds built
                    only from sentences already in your script. Nothing invented.
YOUR NUMBERS ...... Script Writer -> put the figures you looked up in "Verified data", one per
                    line ("Reserves, 2026-07-31: 11.2"). It checks the script against them and
                    flags any figure with no source, plus a sources block for the description.
DEAD AIR .......... Video Studio -> any video -> "What would be cut?" then "Cut it". Removes long
                    pauses, keeps a quarter-second of breath, makes a NEW video (original kept).
DRAW THE CHART .... Charts -> "Draw it on" -> the chart draws itself over 4 seconds. Record the
                    screen while it plays and lay it over your narration.
YOUR CHANNEL+ ..... same tab: "Find the gaps" shows subjects other channels get views on
                    that you have NEVER covered, with their real videos so you can check it
CREDITS CHECK ..... Video Studio -> any video -> "Check before publishing". NOT a copyright
                    detector (nothing on a PC can be one) — it checks whether a licence
                    needs a credit and whether that credit is really in your description
BOTH LANGUAGES .... Script Writer -> "Upload in both languages". Roman Urdu is ur-Latn, not
                    en and not ur; the wrong code quietly costs you reach
THUMBNAILS ........ Script Writer -> "Test two thumbnails properly". Different variants,
                    plus the sum that says whether a difference is REAL or just chance
UNDO IN SCENES ..... Scene Studio -> Ctrl+Z, like the Timeline and Storyboard already had
CRASHES ........... if the app ever closes on its own it now says so and writes it into
                    Settings -> Known Issues first, instead of vanishing silently
RENDER FAILED? .... just press Build again. It reuses the narration it already recorded
                    (the slow part) instead of speaking the whole script over. Only ever
                    for the SAME words in the SAME voice - change a word and it starts fresh
WATCH ONE SCENE ... Scene Studio -> any finished scene -> "Watch this scene". A few seconds,
                    with the real camera move and look, instead of rendering the whole video
BIG VIDEO LAGGY ... Timeline Editor -> "Scrub smoothly" on any clip over 1080p. Edits a small
                    stand-in; your cuts land in exactly the same place; the finished video is
                    still made from the full-quality original
QUIETLY BETTER .... every render now: one encode instead of four (less quality lost), audio at
                    YouTube's own -14 LUFS target (so it stops turning you down), slow camera
                    movement on footage instead of a frozen frame, scene lengths that tighten
                    toward the end, b-roll that lands on the word it belongs to, and a 1-second
                    pre-flight check that fails fast instead of 20 minutes in.

ONE VERSION EVERYWHERE — HOW TO CHECK (new)
Laptop:     sidebar, gold badge under "OS" -> version · date-time · code id. The code id is proof.
Phone app:  Settings -> bottom -> "This app's version" (+ "Check for a newer version" button).
The old copy is always REPLACED, never left running beside the new one. If the phone looks old,
it reloads itself now; if not, press that button or close and reopen the tab.
The installer alone upgrades NOTHING — it installs whichever file is already there. A new file
only exists after a build.

RECORDING QUALITY (new)
Recorder -> Camera / Screen / 🎙 Voice only - no face. Resolution + frames-per-second + Quality.
Bitrate is set to YouTube's own upload figures (1080p30 = 8 Mbps, 4K30 = 45) - browsers otherwise
default to ~2.5 Mbps at any size, which is why phone video looks soft. The figure and the MB-per-
minute are shown before you record, and it tells you what the camera actually gave.
Voice only = no camera opened at all; saved as an audio track for scenes/stock footage.
On the phone app: "🎥 Film it now" opens your phone's OWN camera app (real sensor, hardware
encoding, stabilisation) - much better than filming inside a web page. 🤳 = front camera.

TELEPROMPTER (new)
Sidebar -> 🧾 Teleprompter (also a Prompter tab in the phone app). Paste script -> Start.
Speed is in words-per-minute; "Finish in: 10 min" sets it exactly. Your [BRACKETED] notes show
dimmed and are never counted in the timing. Space = pause · arrows = speed · phone: tap the text.
Recorder asks HOW you record (laptop webcam / laptop screen / phone camera / phone screen / voice only)
and tells you where to put the prompter so it stays out of the shot. Countdown: None/3/5/10/20/30s.
Prompter opens in its own window and can ask Windows to hide it from screen recordings.
