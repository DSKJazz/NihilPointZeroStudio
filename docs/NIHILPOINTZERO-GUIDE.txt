1. WHAT THIS IS / FIRST LAUNCH
-------------------------------------------------------------------------------
You type (or speak) an idea; the app writes a script, makes the visuals, adds a
voice, music and captions, and gives you a finished video — or you record your own
voice over it. Most of it is FREE and offline. The smart-AI bits use the internet
(also free — keys are built in).

TWO WAYS TO RUN IT:
  PORTABLE (the classic way): double-click NIHILPOINTZERO-OS-portable.exe ONCE and
  wait ~40-60s (no window shows while it unpacks — normal). This is the copy that
  travels on a USB with your whole folder.
  INSTALLED (recommended for daily use on THIS PC): run NIHILPOINTZERO-OS-setup.exe
  once. From then on the app opens in ~2 seconds, taskbar pins are SAFE, and it uses
  the SAME nihilpointzero-data folder — your videos/settings appear in both versions.
If SmartScreen warns: More info -> Run anyway (it's safe, just unsigned). The
"NIHILPOINTZERO-OS" Desktop shortcut points at the portable exe.

WHICH BUILD AM I RUNNING? The sidebar shows a small gold badge under "OS", e.g.
"v0.1.1 · 2026-07-19 15:59 · 4e5e704" — that's version · the exact date+time the
build was made · a code id. It is stamped AUTOMATICALLY when the app is built, so it
can never be wrong or forgotten; it is proof of which code is running.
IMPORTANT (PORTABLE EXE ONLY): do NOT pin the portable app to the taskbar/Start
WHILE it's open — Windows freezes that pin to a temporary unpacked copy and it will
launch OLD code forever. Launch from the Desktop shortcut or the .exe in this folder.
The INSTALLED version has no such trap — pin it freely. (The pin trap once made hours
of updates look like "nothing changed".) See §13 if a build looks stale.

2. THE ONE RULE + MOVING TO ANOTHER PC
-------------------------------------------------------------------------------
Your work lives inside the "nihilpointzero-data" folder next to the .exe. ALWAYS
copy the WHOLE "NihilPointZeroStudio" folder — never just the .exe — or your work
won't be found.

Copy the folder to another PC and:
  TRAVELS AUTOMATICALLY: all videos, scripts, Script Pad, library, settings, the
     built-in free keys, and the Natural voice (if downloaded).
  NEEDS INTERNET (no install): AI writing/images/visuals, put-me-in-a-scene, online
     music removal.
  YOU REDO ONCE (optional): offline Demucs music separation — it's a Python program
     tied to a machine. On the new PC: install Python (python.org), then in a command
     window run  python -m pip install demucs numpy , then Settings -> "Music
     separation (local)" -> type  python -m demucs  -> Save. You do NOT need this if
     you have internet (the Online button already removes music).

  ✓ AM I UP TO DATE? Settings → the Version box at the top of the page. It states it

  🔌 IT OPENS WITH WINDOWS, AND UPDATES ITSELF THEN: the studio is registered with
     Windows to open when you sign in. That moment is deliberately chosen: nobody is
     waiting for the app and nothing is running, so it is the only safe time to spend
     a few minutes replacing itself. If it finds a newer version it downloads and
     installs it there and then, and you sit down to the newest version having pressed
     nothing.
     Three rules it will not break:
       - it never updates while a render or a queue is running — your work is never
         interrupted, which is the one rule this app does not bend;
       - if the download finishes and by then you HAVE started something, it holds the

         (there is nothing left to fetch);
       - if YOU opened the app rather than Windows, it never hijacks you — you get the
         notice and you choose.

  ⬆ THE APP UPDATES ITSELF: on startup it quietly checks whether a newer version was
     published. If yes, a small blue notice appears at the bottom of the window. Press
     "Get the update" and the app does the whole job — downloads the update (you see a
     progress bar), checks it really is the file GitHub published, starts it, and closes
     itself so the update can finish. Windows asks once whether to allow it; say yes,
     and the app reopens updated.
     You never open a web page, a Downloads folder or File Explorer. If the download is
     interrupted, press the button again — it keeps the part it already has.
     Behind that one button are three routes, best first: an instant restart when the
     new code is already on disk, then the download-and-install above, and only if both
     fail does it fall back to showing you the setup file and saying so in words.
     Offline? The check silently skips; it never blocks or nags.
  📌 THE FOLDER IS NOW PINNED: the app decides where your work lives ONCE, writes it
     down, and reads that from then on. It used to re-decide on every launch, which is
     how work could "disappear" — the app had quietly moved to a different folder.
     If the recorded folder is ever unreachable (external drive unplugged, folder
     renamed) the app tells you plainly, confirms nothing was deleted, and keeps
     working from a safe fallback until the drive is back. A portable exe on a USB
     stick still always uses the data beside it — that is intended.
  📍 WHERE YOUR WORK IS KEPT (Settings, just above Backups): the app names the exact
     folder holding your videos, scripts and settings — no more guessing. The app can
     legitimately use one of three folders (next to the portable exe / the Desktop
     studio folder / your private Windows folder), and work made while one was active
     used to VANISH from view when another took over. Now the app looks for that and
     tells you — in this card and in the Activity Log — with a one-click
     "Bring them into the app" that COPIES those videos in. It never moves or deletes
     anything; the other folder is left exactly as it was.
  💾 BACKUPS (Settings → Backups — and automatic): your work is copied to
     C:\Users\<you>\NihilPointZero-Backups (it moved there from Documents; the app moves
     the old folder for you automatically). The app backs up by itself at most once every
     7 days; "Back up now" in Settings does it on demand, and BACKUP-NOW.cmd in the
     Desktop studio folder still works too. It only adds/updates, never deletes.
     RESTORE (the part that matters in a disaster): Settings → Backups → "Restore missing
     files" copies back anything that is in the backup but MISSING from the app. It never
     overwrites anything you currently have — completely safe to press.
     SECOND HOME: pick a folder on a USB stick or second disk and every weekly backup is
     copied there too. A backup on the same disk cannot survive a disk failure — this one
     can. If the drive is unplugged that week, it's skipped and noted, never an error.
     DELETE-SYNC (on by default): when you permanently delete a video in the app, its
     backup copy is deleted too — deleted means GONE FOR GOOD, no ghost copies left
     behind. Turn it off in Settings → Backups if you'd rather backups keep everything.
     "Clean deleted-items ghosts" removes backup copies of things you deleted BEFORE
     delete-sync existed — it shows you the count and size first, and asks.
     WHAT IS AND ISN'T COPIED: videos, thumbnails, scripts, library, drafts and logs —
     with NO size limit, so your biggest finished videos are protected. Your API keys and
     the app's browser data are deliberately EXCLUDED (the backup folder may be cloud-
     synced, and in the portable copy saved keys can be read back — they must not travel).
     If any file can't be copied, the Activity Log says INCOMPLETE and it retries next
     time you open the app — it never claims success it didn't achieve.
  🩺 "RUN FULL CHECK" (Settings, top-right of Setup health): the most useful button in the
     app when something feels off. It really tests everything — internet, the free AI, the
     free image service, Ollama (and whether your chosen model is installed), and whether
     your saved Anthropic/OpenAI key is actually ACCEPTED. A wrong key turns RED with the
     reason. Green = truly working, not just "saved".
     AUTOMATIC TOO: the same check quietly runs by itself about once a week. If it finds
     a real problem, a small RED DOT appears on "Settings" in the sidebar and a plain-
     English line lands in the Activity Log — problems announce themselves instead of
     waiting to be discovered mid-project.
  🈳 DISK-SPACE GUARD: if your disk is almost full, video builds now say so up front
     ("This disk is almost full…") instead of failing halfway with a confusing error —
     and warn you early when space is merely getting low.
  🏠 TODAY (first sidebar item): the app opens here — latest videos, recent activity, and
     one-click cards to start the usual jobs. Ideas & Trends is now the item just below it.
  🏷 POSTING TEXT (Video Studio, under each video): one click writes a title, description
     and hashtags for that clip, each with its own Copy button — made for pasting straight
     into YouTube/TikTok after cutting shorts.

5. THE BUILD CHOICES
-------------------------------------------------------------------------------
VIDEO LOOK (engine) — what makes the visuals. Five tiers:
   Style presets              - free, offline. Styled text, backgrounds and your own
                                images. Always works, no key.
   Photo slideshow (AI images) - free, online, no key. A real AI image per scene,
                                panned and zoomed. A moving photo slideshow — not
                                filmed motion.
   REAL AI video — free cloud - free, online. REAL moving video per scene — not a
                                slideshow. Two free routes, chosen in Settings ->
                                AI Video: a free Pollinations key (Quest Pollen,
                                signup by GitHub/email — NO phone number) or a free
                                Puter account (Google Veo, sign-in window; their
                                phone verification rejects some countries' numbers,
                                Pakistan included). Up to 5 scenes per build get
                                real motion (adjustable) and the rest use AI stills;
                                each real-motion scene takes minutes. If it can't
                                run, scenes fall back to AI stills and the build
                                log says why. (See §18.)
   AI footage (cloud)         - paid; real AI footage from a provider you supply your
                                own key for.
   REAL AI video — local GPU (ComfyUI) - free per video and fully private, but needs a
                                dedicated NVIDIA card. On this PC it is visible but
                                greyed out: "Requires NVIDIA GPU — not detected on
                                this system". (See §18.)
LOOK (template):
   Clean     - plain and fast.
   News      - crisp colour + sliding "lower-third" bars showing the section label.
   Cinematic - colour-graded + vignette + film grain + black cinema bars (letterbox).
   Bold      - punchy colours.
   All add a smooth animated title, and section titles slide up as they appear.
FORMAT (shape): 16:9 = YouTube · 9:16 = Shorts/Reels/TikTok · 1:1 = square.
RESOLUTION: 1080p (fastest) · 1440p · 4K (sharp, slower) · 8K (very slow, huge).
   4K is the sweet spot. For Shorts pick the 9:16 shape.

6. VOICE — 4 WAYS (yours is best; two are free natural Urdu options)
-------------------------------------------------------------------------------
  (A) YOUR OWN voice (recommended): build the video, then "🎙 Voice studio" under it:
        Record with ⏸ Pause / ▶ Resume; after Stop, drag the slider to review;
        "Redo from playhead" keeps the part before and re-records the rest;
        finish with "Replace the narration" OR "Keep existing audio + add my voice".
  (B) WINDOWS NATURAL voice (free, no download): pick "Narration voice -> Windows
        natural voice". Windows itself ships free voices per installed language —
        including real Urdu (Pakistan): Asad and Uzma. If you don't see them, click
        "+ Add Urdu / more voices" (in the picker, or Settings) to install the free
        Urdu language pack in Windows, then reopen this tab. "🔊 Hear this voice"
        lets you preview before committing.
  (C) NATURAL voice (Piper): a nice computer voice with NO Windows setup needed.
        Pick and download a voice in Settings — includes two real Urdu neural
        voices (male "Fasih", female "Aegis", ~60 MB each) alongside English ones.
        Then pick "Narration voice -> Natural voice (Piper)" when building.
  (D) WINDOWS voice: basic/robotic, always free, good for a quick draft.

8. MUSIC & THE DJ STUDIO
-------------------------------------------------------------------------------
Video Studio -> "Sound Studio (DJ)":
   - Library: generated music moods, sound effects, a bundled pack, your own files,
     and "Find free music online" (legal, no-copyright search).
   - Timeline: place sounds (start time, volume, use only a slice).
   - "🎵 Create music only": render the timeline to an MP3 and SAVE it (no video).

   - "📊 Show waveform": see the audio of the selected video (loud/quiet spots).

Remove or swap the background music (and now the VOICE too):
   - Videos MADE IN THIS APP: the "🎵 Music" row -> Remove (keeps your voice) or
     Replace with a mood. Replace AUTO-DUCKS: the music dips whenever you speak.
     Exact and instant, no internet. NEW: "Remove my voice (keep music)" does the
     opposite — AI-separates the mixed audio and keeps only the music.
   - OUTSIDE videos (music already mixed in): "Remove music (AI separate)":
       Online = works out of the box (free, built in), needs internet.
       Local  = offline, best quality (Demucs, installed on this PC).
     NEW: the same row also has "Keep music (online/local)" = remove the voice instead.
     Separation is an AI estimate — great for clear speech over music, not perfect.

🎧 THE AI DJ (in the same "🎵 Music" row, one click):
   - Leave the little box empty and press "Let the AI DJ pick & lay the music": the app
     reads the video's OWN script (videos now remember their script), or listens to the
     narration if there isn't one, judges the mood (English, Roman Urdu AND Urdu script),
     composes a track sized to the video, and mixes it softly under your voice.
   - Or type what you want ("lofi", "tense", "calm", "cinematic"…) and it obeys.
   - Always a NEW copy — your original stays in the list.

🧹 CLEAN COPY (the "🎛 Studio tools" row under each video):
   - One click rebuilds the exact same video with NOTHING written on the picture —
     no title, no section headings, no captions. Works for videos built from now on
     (they remember their own recipe). Burned-caption copies never replaced your
     original anyway — it is always still in the list.

🎛 OPEN AUDIO IN DJ DECKS (same row): pulls the video's sound out and loads it onto
   Deck A of the Dual decks (EQ, loops, hot cues, BPM, crossfader) in one click.

9. SCENE STUDIO (storyboard + put yourself in a scene)
-------------------------------------------------------------------------------
🎬 Scene Studio builds a video one scene at a time:
   - "Plan scenes" turns your script into scene cards (each with an editable prompt).
   - "Generate all" makes an image per scene — watch them appear. ⏸ Pause / ▶ Resume.
   - STORYBOARD: reorder scenes (↑ ↓), remove (✕), or "＋ Add a scene". The order you
     see is the order the video is built in.
   - Rewrite any scene's prompt and "↻ Regenerate this scene". If a regenerate fails,
     the reason now shows in red ON the scene card (it used to hide behind the old image).
   - ⏱ YOUR PACING (new): every scene card has "Stays … sec" (how long that image is on
     screen) and "✨ Arrives by" (straight cut, fade, dissolve, slide from any side,
     circle open). Leave them empty for automatic pacing. Set them and every image
     shows exactly once, in your order, at your pace — the total is always stretched
     to fit the narration, so speech never gets cut off.
   - 🎬 VIDEO SETTINGS row (above the scenes): Style · Video look · Resolution ·
     Format · Look — these decide the final built video.
   - "📎 Put me in (photo)": attach your picture and describe the scene ("me as an
     astronaut, spacesuit, on the moon"). Slider "Photo transform" — lower keeps more
     of your real look. Free; uses internet; the queue can be slow (shows its place).
     Exact face likeness isn't guaranteed on free AI.
   - "🎬 Build video" stitches the approved scenes with narration, your Look, etc.
   - "VIDEO LOOK" selector: the final build can use your generated stills (classic,
     default) or REAL AI motion per scene — free cloud (Pollinations key or Puter sign-in) or local
     GPU (needs NVIDIA). Same rules and honest catches as Video Studio's engine
     list (§5, §18).
   - BEAUTIFY: a slider retouches your uploaded photo (skin-smooth + brighten + sharpen)
     on your REAL pixels — no invented face. This is a light retouch, not AI makeup.

9b. STORYBOARD DIRECTOR (direct it shot by shot)
-------------------------------------------------------------------------------
🎞 Storyboard Director is for full creative control of the visuals, beat by beat.
   - AUTO mode: paste a whole script (and a title) and the AI DECIDES everything —
     topic, mood, genre, style, and the whole shot breakdown.
   - GUIDED mode: you write the shots yourself, e.g. "0-15s I arrive in a Ferrari and
     say '…'; then 20s a helicopter over the hills, slow fade; then 90s of me speaking".
   LENGTH GUARD: the "aim for … seconds" box is capped at 60 minutes, and before
   rendering anything longer than 20 minutes — or anything with NO narration on any
   shot — the app tells you what it is about to make (how many shots, how long,
   whether it will be silent) and lets you cancel. One project once asked for 9,999
   seconds and quietly produced 78 minutes of silence; that cannot happen now.
   Each SHOT has: a length in seconds, a SCENE description (what to show), optional
   narration and an on-screen caption, a camera MOTION, a crossfade INTO it, and its own
   SOUNDS (add a music bed, a sound effect, or your own audio file — each with gain,
   fade-in/out and a start offset). You can reorder shots (↑↓) and delete them (with a
   confirm).
   SUBJECT per shot — who's on screen: (a) Scene only (AI/stock scene), (b) MY PHOTO —
   your real photo is beautified, background-removed and composited INTO the AI scene
   (your true face, not a fake), (c) MY CLIP — your own footage, (d) AI PERSON — a
   generated character (described by you; not your real face).
   BEAUTIFY: "Set my photo", then a slider — RIGHT smooths skin / brightens / evens tone,
   LEFT makes it grittier & sharper. It edits YOUR real pixels (a retouch, not AI makeup).
   Preview it before rendering.
   Build makes each shot, holds it for the right length (narration decides the length, so
   speech is never cut off or overlapped), crossfades between shots, lays narration +
   captions + your sounds, and opens the finished film in the ✂ Timeline Editor so you can
   fine-tune anything.
   SCENES SELECTOR: by default AI scenes are animated stills, but the "Scenes:"
   selector can switch them to REAL AI video — free cloud (Pollinations key or Puter sign-in, a few
   scenes per build, minutes per scene) or local GPU (needs NVIDIA). See §18.
   HONEST LIMITS (free): unless you pick a REAL-video engine above, AI scenes are
   STILLS with Ken-Burns motion, not real moving footage — and even with the free
   cloud engine, scenes past the per-build cap use AI stills.
   Your real face is kept by compositing your ACTUAL photo/clip — the app never
   fabricates a fake video of your face. The background cutout uses a small free model that
   downloads once on first use; if it can't (offline), it falls back to your photo framed

13. TROUBLESHOOTING
-------------------------------------------------------------------------------
- Nothing on first double-click (portable exe): wait ~60s; don't double-click again.
  (The installed version opens in ~2s — run NIHILPOINTZERO-OS-setup.exe once to get it.)
- "My updates/changes didn't show up" / old look: check the BUILD BADGE in the sidebar
  (under "OS"). If it's older than expected you launched a STALE copy — this happens when
  you pinned the PORTABLE app to the taskbar/Start while it was running (Windows freezes
  the pin to a temporary unpacked folder). Fix: launch the DESKTOP shortcut or the .exe in
  the folder directly — or switch to the INSTALLED version, which can never go stale this
  way. The exe on disk is always the newest — the pin was pointing at old unpacked code.
- Live PSX Data with no internet / portal down: you'll see an amber banner and your last
  SAVED data (clearly dated). That's deliberate — real numbers from your last fetch, never
  invented ones. Fetch again when you're back online.
- "file not found" after moving: fully close and reopen; keep the whole folder together.
- An online feature errors: check internet, try again.
- A build fails at a weird resolution: it auto-retries safely; if not, use 1080p/4K.
- Writing stopped after changing provider: set it to "Free (online)" in Settings
  (needs no key), or make sure Ollama / your paid key is set up.
- An amber warning appears: "Your ... AI failed — this answer came from the free AI
  instead": your chosen paid/local AI could not answer, so the app used the basic free
  AI (answers will be noticeably weaker). Most common cause: a wrong, expired, or
  out-of-credit API key — open Settings and re-paste your key (an Anthropic key starts
  with "sk-ant-api..." and is very long; copy ALL of it). If your provider is Ollama,
  make sure Ollama is installed and running. The full technical reason is kept in the
  Activity Log. If you see NO warning, your chosen AI answered normally.
- A "real motion" scene came out as a still: the free cloud allowance ran out (it is
  small and monthly), the per-build cap was reached, or the service couldn't be
  reached — the build log says which. Falling back to AI stills is deliberate, so the
  build never breaks.
- A tab crashes / goes blank: the failure is contained to THAT tab — the rest of the
  studio keeps working. You get a plain-English message and a "Try this tab again"
  button, and the crash is written to Settings -> "Known Issues" so it's provable.
- Multiple copies open / won't launch: close all "NIHILPOINTZERO-OS" in Task Manager,
  then open once.

21. NEW (2026-08-01): RECORDING THAT DOESN'T LOOK LIKE A PHONE
-------------------------------------------------------------------------------

THE THING NOBODY TELLS YOU: IT IS NOT THE RESOLUTION
Everyone reaches for 4K, and 4K is not what gives a phone recording away. The
bitrate is — how many bits per second are spent on the picture. Every browser,
left alone, records at roughly 2.5 megabits per second WHATEVER size you asked
for. That is about a third of what 1080p needs and a fifteenth of what 4K needs.
Record 4K at the default and you get a file that is bigger than 1080p and looks
worse: soft, and blocky whenever anything moves.

The Recorder now sets it properly. The figures come straight from YouTube's own
published guidance for uploads:

      1080p at 30 fps ....  8 Mbps        1080p at 60 fps ....  12 Mbps
      1440p at 30 fps ....  16 Mbps       1440p at 60 fps ....  24 Mbps
      4K    at 30 fps ....  45 Mbps       4K    at 60 fps ....  68 Mbps

You do not have to know any of that. The Recorder shows you the number it is
using and roughly how many MB a minute will cost, before you press record.

THE CONTROLS
  Resolution     720p / 1080p / 1440p / 4K.
  Frames/second  24 (cinematic) · 30 (normal talking head) · 60 (smooth — best
                 for screens, movement, anything fast).
  Quality        Balanced (smaller files) · YouTube quality (the right answer
                 almost always) · Master (well above what YouTube needs, for
                 footage you are going to cut and re-export).

  It also tells you what your camera ACTUALLY gave. Ask for 4K on a camera that
  tops out at 1080p and it says so, instead of leaving you wondering why the
  footage looks soft.

WITH YOUR FACE, OR WITHOUT
  🎙 VOICE ONLY - NO FACE opens no camera at all. No permission prompt, no camera
  light, nothing that could end up in the file. Your narration is saved as an
  audio track, ready to put under scenes, charts, stock footage or your own clips.
  Tick "Clean up my voice on save" and it gets the same de-noise, levelling and
  broadcast loudness the video enhancer uses — so you sound identical whether or
  not you were on camera.

FILMING ON THE PHONE — USE THE PHONE'S OWN CAMERA APP
  In the phone app's scene editor there are now two filming buttons:
      🎥 Film it now (back camera)      🤳 Film me (front camera)
  These open your phone's REAL camera app rather than recording inside the web
  page. That matters more than any setting here: the camera app uses the actual
  sensor pipeline, the hardware encoder, stabilisation and proper autofocus. A web
  page cannot get close. The clip comes back and attaches to the scene exactly
  like one picked from your gallery.

  When you record inside the studio ON your phone (Route 2), a long take is saved
  to the phone's own Downloads rather than squeezed over the link — a 4K take runs
  to gigabytes. Short takes go straight to the PC. Either way the take is never
  lost; the app tells you which happened.

NOTHING IS THROWN AWAY WHEN IT SAVES
  Recordings are usually captured as H.264 now, which is also what the studio

THE EXPERT NOW WORKS WITH NO AI AT ALL

22. NEW (2026-08-01): ONE VERSION EVERYWHERE — AND HOW TO CHECK
-------------------------------------------------------------------------------

THE RULE
There is only ever ONE live version of this studio. When something is upgraded,
the old copy is REPLACED — it is never left running quietly beside the new one.
Five places, and they always match:

  1. the workshop folder (where the code lives)
  2. the Desktop studio folder
  3. the installed Windows app
  4. GitHub
  5. YOUR PHONE — both the app you installed from the web, and the studio served
     from this PC

HOW TO CHECK, IN FIVE SECONDS
  ON THE LAPTOP: the small gold badge in the sidebar, under "OS". It reads the
  version, the build date and time, and a short code id like `a1b2c3d`. That code
  id is the only honest proof of which build is running. If it has not changed
  after an update, the update did not take.

  ON THE PHONE: Settings, at the very bottom — "This app's version". Same idea,
  same stamp. There is a "Check for a newer version" button next to it.

WHY THE PHONE NEEDED ITS OWN FIX
A phone app is stored ON the handset so it can open with no signal — that is the
point of it. But it means publishing a new version does not remove the old one.
The phone could go on showing last week's app for days, and nothing on the screen
would tell you. That actually happened.

Now: every build stamps its own identity into the phone app's storage, so the
previous version's files are deleted rather than left behind; the app notices a
new version has arrived and reloads itself once; and the version is printed in
Settings so you can always read it off the screen.

If the phone ever still looks old — press "Check for a newer version" in Settings,
or just close the tab and open it again.

ONE THING THAT CATCHES EVERYONE
Running NIHILPOINTZERO-OS-setup.exe does NOT upgrade anything by itself. It
installs whichever file is already sitting in the folder. A new file only appears
after a build — either `npm run ship` on this PC, or the automatic build on
GitHub. So if you install and the badge has not changed, nothing was wrong: there
was simply no new file yet.

23. NEW (2026-08-01): YOUR CHANNEL — LEARNING FROM WHAT ALREADY WORKED
-------------------------------------------------------------------------------

WHY THIS TAB IS DIFFERENT FROM EVERY OTHER ONE
Every other tab in this studio helps you make the NEXT video. This one tells you
what already worked on the LAST forty. It is the only tab that reads your own
history back to you, and it is the only advice in here that is actually about
your channel rather than about channels in general.

"Use numbers in titles." "Post at 6pm." "Keep it under 60 characters." All of
that is an average across millions of channels that are not yours, aimed at an
audience that is not yours. A Pakistani finance channel spoken in Roman Urdu has
an audience with its own habits, and the only data that describes those habits is
already sitting in your own uploads. Nothing was reading it.

YOUR AI BRAINS — THE SWITCHBOARD
Settings has a switchboard: every AI brain the studio can use, each with a plain
ON/OFF switch and a "Use this one" button. OFF genuinely means off — a switched-off
brain is never contacted, not even as a backup. The old free online service (the one
that started demanding payment in 2026) sits OFF; your local brain (Ollama) stays ON.

GEMINI, FREE. Google gives Gemini away through a free key — no card, a daily
allowance that renews itself. Settings -> "Connect Gemini" -> "Show me how": two
minutes, a button for each step, and the key is tested against Google for real before
it is saved. Saving it switches Gemini ON.

CHATGPT AND GROK. Their websites are free but their machinery is not — there is no
free key for an app to use, and the only way to fake one would be storing your
passwords, which this studio will never do. They get open-in-browser buttons instead.

WHAT YOU NEED FIRST
Settings -> "Connect YouTube". It is free, it takes about three minutes, and
Google never asks for a card.

There used to be one sentence here telling you to go to the Google Cloud Console
and create an API key. That was an accurate sentence and a useless one, so it is
gone. Open Settings and press "Show me how" instead. You get five numbered steps,
each with a button that opens the exact page — no hunting through menus — and
then you paste the key and press Check.

Check is the part that matters. The app makes one real request with your key and
tells you in plain English what happened. If it does not work it names which of
the five steps to go back to. The commonest problem by far is a perfectly good
key on a project where the YouTube service was never switched on, and the app now
says exactly that instead of leaving you to guess whether the key was mistyped.

Then step 6 asks which channel is yours, and you type your @name — the same thing
you see on your own channel page. The app finds the long "UC..." ID for you and
shows you the channel name it found, so you can see it picked the right one. That
ID is buried three menus deep inside YouTube's Advanced settings and nobody knows
it by heart; you no longer need to.

If any of this ever stops working, Settings -> Connect YouTube -> "Check the saved
key" re-runs the same test on demand and tells you the answer.

Reading a hundred of your own videos costs about four of the ten thousand requests
Google gives you every day, so you can run this as often as you like.

IF A PANEL COMES BACK EMPTY, IT NOW TELLS YOU WHY
It used to say "no videos could be read, check your key and channel ID" whatever
had happened — including when nothing was wrong at all. Seven different things
can happen and they are now told apart:

  - no key yet, with a button that takes you straight to the walkthrough
  - there is a key but the app does not know which channel is yours
  - Google refused the request, and it says which reason Google gave
  - Google itself had a problem (amber) — this says nothing about your key and
    nothing needs fixing; try again in a few minutes
  - it could not reach YouTube at all (amber) — this is NOT the app claiming you
    have no videos, it is the app saying it does not know
  - only part of your channel could be read — what is shown is real, but the
    numbers are a floor rather than a total, and it says so
  - everything is set up correctly and the channel simply has no videos yet,
    which is not a fault at all

The colours mean something. Red is "this is wrong and here is the fix". Amber is
"I could not tell" — never treat amber as a fault to chase. Gold with a button is
"three minutes of setup and this works".

WORK IT OUT — WHAT THE THREE ANSWERS MEAN

  WHICH TITLE SHAPES WORKED. It tries eight shapes against your history — has a
  number, is a question, names an institution (SBP, PSX, IMF), mentions the rupee
  or the dollar, written in Roman Urdu, short, has capitals, promises an
  explanation — and reports which of them your audience actually rewarded.

  It uses the MIDDLE video, not the average. One video that went viral drags an
  average so far that every conclusion becomes "do what that one did", which is
  usually luck you cannot repeat. The middle video is the one you are about to
  make.

  It refuses to answer more often than it answers, on purpose. Below eight videos
  it says "not enough videos to tell yet". If nineteen of your titles have a
  number and one does not, it also says that — one video is not a control group.
  And a difference under 10% is called no real difference, because it is noise and
  chasing it would waste a year. Every claim you DO get carries the number of
  videos behind it, right in the sentence.

  WHEN YOUR AUDIENCE SHOWS UP. Your videos grouped by day, and separately by
  hour. Separately, because there are 168 day-and-hour combinations and you would
  need thousands of videos before any single one of them meant anything. A single
  freak result at 3am will never be recommended to you.

  TRY A TITLE ON IT. Type a title you are considering and it scores it against
  your own history — and tells you WHY, not just a number. "Missing a number,
  which is worth about +130% for you" is something you can act on. A score of 73
  is not. If there is not enough history to score honestly, it says so and tells
  you that general advice is all anyone could offer, and that it is worth less
  than your own data will be.

YOUR SERIES — READ OUT OF YOUR OWN TITLES
A standalone video ends and the viewer leaves. An episode ends and there is
somewhere to go. This finds your series without you tagging anything, by reading
the titles you already published: #4, Part 2, Episode 3, Ep 3, E03, "2 of 5", and
Hissa 2 and Qist 3 in Roman Urdu.

It is deliberately cautious about what counts as an episode number, because the
output goes into a PUBLISHED description where a wrong guess stays wrong.
"Budget 2026" is not episode 2026. "PSX crosses 78000" is not episode 78000.
"Reserves at 11" is not episode 11. A number only counts when there is a real
marker in front of it.

What it gives you:
  • which of your videos belong together, in EPISODE order — not upload order,
    which is what puts episode 4 before episode 3 in a playlist when you publish
    out of sequence
  • a warning when a number is missing from the middle of a run, or when two
    videos both claim the same number (this accumulates quietly and is a real mess)
  • the next episode number to use
  • three blocks ready to paste: the description links, the pinned comment (which
    is where the next click actually happens), and the end-screen line

It will never write "Next: episode 5" under episode 4 before episode 5 exists.

READ MY COMMENTS — THE CHEAPEST IDEA SOURCE THERE IS
Every other way of finding a video idea is a guess about what people want. Your
comments are people telling you, in their own words, unprompted. And the same
question asked forty times is a video with a guaranteed audience before you
record a frame. It is also the one source no competitor can copy, because they
are your commenters.

Nobody reads two thousand comments. That is the only reason this is not already
everybody's process.

It reads the comments on your recent videos, pulls out the questions, groups the
ones asking the same thing, and ranks them by how many DIFFERENT people asked.
Two things worth knowing about how it works:

  • Roman Urdu questions usually carry no question mark at all. Relying on "?"
    would silently throw away half your comments, so it recognises question words
    in both languages instead.
  • Every question it shows you is quoted word for word from a real comment. No AI
    summarises them. An AI summary of "what people are asking" reads beautifully
    and may correspond to nothing anybody actually wrote — and there is no way to
    tell from looking at it. You can check a quote.

Likes are used only to break ties, and capped, so that two heavily-liked comments
can never outrank five people independently asking the same thing. Likes on one
comment are noisy — thread position, a joke that landed. Distinct people asking
is not.

24. NEW (2026-08-01): HEAR IT, AND FIX THE FIRST FIFTEEN SECONDS
-------------------------------------------------------------------------------

READ IT TO ME (Script Writer)
A script is not read. It is SPOKEN. Reading it silently hides exactly the faults
that ruin a take, and you find them at minute nine with the camera running:

  • the sentence you cannot get through in one breath, so you either rush the end
    or breathe in the middle of it — both audible
  • the figure that cannot be read off the page ("11.2bn", "250000", "11-12%")
  • the word written twice in a row, which your eye skips and your ear will not
  • the line that switches between English and Roman Urdu mid-sentence, which is
    fine if you meant it and a stumble if you did not

Listening at normal speed takes as long as the video, so nobody does it twice. It
reads to you at DOUBLE speed instead — a twelve-minute script checks in six
minutes — and the pitch is held, so it still sounds like a person talking quickly
rather than a cartoon. 1.25x to 3x are all there; 2x is the one to use.

It is built to keep quiet unless something is genuinely wrong. A check that flags
forty things in a finance script is a check you turn off after one use, and then
it catches nothing for the rest of time. If it says nothing, it still tells you to
listen anyway — your ear catches what a check cannot.

SHOW 5 OPENINGS (Script Writer)
The first fifteen seconds decide whether the other twelve minutes get watched,
and they are the hardest part of the script to judge from the inside. This shows
you the same material five ways:

  • as a CONTRADICTION — what everyone believes, and why it is wrong
  • as a NUMBER — the figure that makes someone stop
  • as a QUESTION — the one they already have
  • as WHAT IS AT STAKE — what it costs them
  • DROPPED MID-SCENE — starting in the middle, no preamble

Every one is built from a sentence already in your script, and the sentence it
came from is printed underneath so you can check it rather than trust it. Nothing
is invented. "Put it at the top" drops your choice into the draft.

WHERE YOUR NUMBERS CAME FROM (Script Writer)
Your channel lives on its numbers being right. One wrong figure in a video about
the reserves is the comment that gets pinned, and a published video cannot be
edited.

The "Verified data" box has always been where you put the numbers you looked up.
Nothing was reading it back. So a figure could be pasted in correctly and then
mistyped into the narration, and nothing noticed.

Write them one per line, however you naturally would:

    Source: State Bank of Pakistan | https://sbp.org.pk/ecodata
    Reserves, 2026-07-31: 11.2
    Import cover: 2.1
    Source: PSX
    KSE-100 close: 78,412

A "Source:" line applies to everything under it, so you do not repeat it. Lines
with no number are ignored rather than treated as mistakes — it is your own
notepad. Then it checks every figure in your script against them and flags the
ones it cannot trace: those are the ones a comment will ask about. It also writes
the sources block for your description, which is the cheapest credibility there
is and something almost no finance channel bothers to publish.

25. NEW (2026-08-01): DEAD AIR, MOVING CHARTS, AND SIX INVISIBLE FIXES
-------------------------------------------------------------------------------

DEAD AIR (Video Studio, per video)
Two buttons, in this order, and the order is the point.

"What would be cut?" reads the take and tells you: how much dead air, across how
many cuts, and how long the result will be. It changes nothing. This is cheap —
two reads and no re-encode — so it can afford to ask before it acts. A silence
remover that just does it to a finished take is one you will never trust with the
take that matters.

"Cut it" then removes the long pauses. It keeps a quarter-second of breath at
each one, so it still sounds like a person talking rather than a machine gun. It
never touches the opening or the very end — a hard cut in the first moments looks
like a broken file, and the sign-off should not be clipped. And it writes a NEW
video. Your original stays in the list, always.

Picture and sound are cut on exactly the same marks in one pass, which is the
thing that goes wrong in cheap silence removers: the sound gets shorter than the
picture and your lips stop matching your words.

DRAW IT ON (Charts)
A chart that appears all at once is a picture. A chart that draws itself while you
talk over it is the explanation. Press "Draw it on" and the price line, the
candlesticks, both moving averages and the RSI all grow together over four
seconds, then hold. Record the screen while it plays and lay it over your
narration.

THE SIX YOU WILL NEVER SEE — ONLY NOTICE
These need no button and cannot be switched on. They are simply how every render
works now.

  1. ONE ENCODE INSTEAD OF FOUR. Colour, captions, watermark and trimming used to
     each be a separate pass, and every pass throws away a little picture quality
     for good. They now happen together. The loss was measured, not guessed: four
     passes scored 0.9508 against the original, one pass scores 0.9957.

  2. AUDIO AT THE LEVEL YOUTUBE WANTS. YouTube turns every upload down to about
     the same loudness. Delivering louder than that does not make you louder — it
     makes YouTube turn you down, and what you lose is the quiet-to-loud range you
     mixed, not the volume you were chasing. Your videos now arrive at its own
     target.

  3. MOVEMENT ON FOOTAGE. Photos already got a slow camera move. Video clips got
     nothing, and a locked-off frame held for a whole minute is the single thing
     that most makes a video look cheap. Each stretch now gets a slow push in or
     pull out, alternating, so it never creeps in one direction and ends
     uncomfortably tight.

  4. SCENES TIGHTEN TOWARD THE END. The last third of a finance video is where
     people leave, and an even split makes the end feel exactly as slow as the
     beginning when it needs to feel faster. The total length is preserved to the
     frame, so your narration still lines up.

  5. B-ROLL LANDS ON THE WORD. When you say "reserves" or "mehngai", the matching
     footage appears on that word rather than three sentences later. Before, the
     footage changed on an even timer that had nothing to do with what you were
     saying.

  6. A ONE-SECOND CHECK BEFORE THE RENDER. It checks that ffmpeg will actually
     RUN — antivirus quarantine leaves the file sitting exactly where it was and
     simply refuses to execute it, so "the file is there" proves nothing — that
     the folder can be written to, and that there is disk space. If something is
     genuinely broken you find out in a second instead of twenty minutes in with
     nothing to show. It only ever REFUSES for something that would have failed
     anyway; a slow encoder is a warning, never a block, because this studio is
     built to work on any machine.

26. NEW (2026-08-01): "WHAT CHANGED" — SO AN UPGRADE STOPS BEING INVISIBLE
-------------------------------------------------------------------------------

Settings -> What changed.

The gold badge in the sidebar proves WHICH build you are running. It cannot tell
you what that build actually does differently, and so every upgrade until now has
been invisible: the work landed, the app looked identical, and the only way to
find out about a new feature was a chat message that scrolled away.

This lists what is new in the build you are running. Two rules make it worth
reading:

  IT NEVER ADVERTISES SOMETHING THAT IS NOT THERE. This is the normal way a
  release-notes list goes wrong — the note ships before the code, you go looking
  for the button, and the button does not exist. Anything dated after the build
  you are running is WITHHELD, and appears for the first time in the build that
  really contains it.

  IT REMEMBERS PER ITEM, NOT PER DATE. This studio sometimes gets two upgrades in
  an afternoon. A list that remembers "the last version you looked at" loses
  everything that shipped later the same day.

"Mark all as read" clears the count. It deletes nothing — the list is still there.
